# marketium-imweb

마케티움 아임웹 홈페이지에서 쓰는 이미지 호스팅용 저장소.

- 폴더 = 페이지(프로젝트) 단위
- 이미지 주소: `https://cdn.jsdelivr.net/gh/yunkyeong-png/marketium-imweb@main/{폴더}/{파일}?w=600`
- 아임웹 `<img>`에는 `?w=` 쿼리를 반드시 붙일 것 (없으면 아임웹 lazy 로딩이 걸려 이미지가 안 뜸)

| 폴더 | 페이지 |
|---|---|
| `book-landing/reviews/` | 『모든 마케터는 사업가다』 랜딩페이지 — 인스타 리뷰 섹션 |
